# Whole shapes

A test project for the shapes the Graph opens whole: nothing in
`catalog/` has a filled polygon, a raster grid or a ring set wired
counter-clockwise from inner first, so this one has all three, each off
its defaults. It is the plasma pattern with its mapping swapped.

No Graph test or story opens it today; `lp-cli`'s `examples_valid` gate
checks it with every project under `projects/test/`. It came from the
retired mapping lab (`lab/mapping/projects/`, moved 2026-10-28), where it
was the fit project for plan M4.
