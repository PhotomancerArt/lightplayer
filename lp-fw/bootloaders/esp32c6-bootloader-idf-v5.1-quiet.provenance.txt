Provenance: esp32c6-bootloader-idf-v5.1-quiet.bin

What it is
  The ESP32-C6 ESP-IDF second-stage bootloader that espflash 3.3.0 bundles
  (and every LightPlayer C6 shipped with until this file), rebuilt from
  source with one change: CONFIG_BOOTLOADER_LOG_LEVEL_NONE=y. It prints
  nothing on UART0 during a good boot (the stock one prints ~22 lines at
  115,200 baud, ~145 ms of every boot). An assert or abort() still prints:
  those go through esp_rom_printf, not the log.

Proof that the recipe IS the stock bootloader
  `build-c6-bootloader.sh --variant stock --check` builds the same commit with
  ESP-IDF's defaults alone and gets espflash 3.3.0's bundled
  resources/bootloaders/esp32c6-bootloader.bin byte for byte (sha256
  c569fa7d2363da15f6b60ea288aa2396ca3c33b6eed84616bb506feaba7a0528, 21,264 B).

Reproducibility
  Two runs of `--variant quiet` give the same sha256 (above), and so does
  the amd64 image (the opt-in `Bootloader reproducible` workflow).

Image header (before a flasher patches its flash mode/size/frequency)
  chip id 13 (ESP32-C6), chip revision v0.0..v0.99, hash appended
  seg 1  0x4086c410  len 0x00a98   data (not code: never a Saved PC)
  seg 2  0x4086e610  len 0x02404   code
  seg 3  0x40875720  len 0x004e8   code
  Both code ranges lie inside the stock bootloader's
  (0x4086e610..0x40871378, 0x40875720..0x40876f20), the ranges Studio's
  hung-bootloader detection reads a ROM `Saved PC` against
  (lpa_devices::bootloader).
