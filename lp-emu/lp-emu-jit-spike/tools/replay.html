Identity checks per entry: exit pc, cycle count, retired-instruction delta, after-store flag, and all 31 architectural registers, against the native recording. Memory equivalence is enforced transitively — any divergence surfaces as a register or pc mismatch on a later entry, which is exactly how the desk caught its first bug. Only the run calls are timed; fetching, snapshot reloads and the between-entry memory deltas are not. Desk reference (bun/JSC, M2 Max): rec-rb 1.44 ns/instr, rec-rk 1.05.
