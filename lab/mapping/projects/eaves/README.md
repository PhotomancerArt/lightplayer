# Eaves

The mapping lab's fit project for Sean's eave lights (plan M5): two runs of
an ordinary strip along a roofline, each turning its corner on a short
jumper (a path gap: wire, no lamps). The first run fills D10 (its port's
count is 60, the run's lamps), so the second auto-flows on to D9. It is the
plasma pattern with its mapping and output swapped.

`cargo test -p lab-mapping-fit-tests eaves`
