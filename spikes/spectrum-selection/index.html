Spectrum-in-selection — round 2: the you-are-here line vs the ring

Round-1 ruling converged on an idiom, not a single treatment: the you-are-here line — a static spectrum line on the nav axis's edge (bottom for horizontal tabs, leading side for vertical lists) — versus the static ring, which marks a chosen object, not a location. All paint stays STATIC; the animated ring remains hover/drag territory. Sections below put the two head-to-head on each surface, with the surface's real meaning stated so the nav-vs-object call is makeable.

1 · View tabs — horizontal nav → bottom line

Round-1: "T1 or T4 — underline already means current-nav-item, but the ring is prettier." Head-to-head, plus the neutral baseline. The ring here would spend the object mark on a location — see section 4 for where it pays instead.

2 · Workbench tree — this IS navigation

What the selected row means: "Ocean Ripple" is the focused node — the one whose editor is open in the center pane. Clicking a row navigates the workbench there (unified selection: one live surface follows selection). So by the round-1 rule this is a vertical nav list → the side line, like the story-nav. The ring variant is kept for comparison since round-1 leaned T4 "but not if it's nav."

3 · Story-book nav — vertical nav → side line

Round-1 ruled: side line ("a side line indicates selection like a bottom line does on the bigger nav"). Shown converged against baseline only.

4 · Object selection — where the ring lives

Option cards (board pickers, setup choices) are a chosen object, not a location — and they still wear the dying accent today, so they need a selection family regardless. Card-scale radius also lets the conic ring show its full sweep (at tree-row radius it compressed to orange — the attention hue).

Rejected in round 1: T3 low-alpha spectrum wash (too timid to cure "dry", even screen-blended at 16%) · T1 underline inside the tree (an underline is off-axis in a vertical list; the line sits on the leading edge there) · full ring on tree rows as nav (spends the object mark on a location; small radius compresses the sweep to attention-orange).
Decision log
  • Round 2 idiom under test: the you-are-here line (static spectrum, on the nav axis's edge: bottom for horizontal nav, leading side for vertical) vs the static ring (chosen object, never a location). Hover stays the only animated light.
  • Round-1 rulings (Yona, 2026-08-30): tabs = T1-or-T4, lean T1 because underline already means current-nav-item; tree hinges on what selection IS (answered above: it's nav); story-nav = side line.
  • Baseline = PR #478 (full no-hue): neutral underline on tabs, neutral selection border + oklab dirty-mix fill in the tree.
  • "Cool sweep" lever: the full spectrum contains amber/red/orange — the unsaved/error/attention hues that sit beside selection in a dirty tree. The Primary tri cannot collide.
  • Status hues untouched; dirty derivation (color-mix into selection fill) preserved everywhere.
  • Wanted alongside production work: a design-language page as the design library's main page — the visual twin of docs/style/ui.md Color & Light (idioms: status families, kinds of light, selection grammar, glass). Goes in the yona-plan as a deliverable.
