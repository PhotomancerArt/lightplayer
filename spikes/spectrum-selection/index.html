Spectrum-in-selection — how much rainbow can "you are here" wear?

Post accent-reckoning, chrome is fully no-hue and Yona's read is "a bit dry — I like the rainbow." This spike tests amending the standing rule "selection is the neutral outline, never the spectrum" with STATIC (pinned, never animated) spectrum paint, so selected and hovered stay different KINDS of light: hover moves, selection doesn't. Baseline T0 is the shipped post-#478 neutral. Judge each treatment where it's hardest: a tree where hovered, selected, and dirty rows touch.

Decision log
  • Baseline = PR #478 (full no-hue): neutral 2.5px underline on tabs, neutral selection border + oklab dirty-mix fill in the tree.
  • All spectrum selection paint is STATIC — the animated conic ring stays hover/drag-only, keeping "moving light = transient pointer state" intact.
  • "Cool sweep" control exists because the full spectrum contains amber/red/orange — the exact hues of the unsaved/error/attention families that sit beside selection in a dirty tree. The tri-gradient (gradient-Primary stops) cannot collide.
  • Status hues untouched; dirty derivation (color-mix into selection fill) preserved in every treatment.
  • T3 keeps the neutral border — the smallest possible amendment to the ui.md rule ("the outline stays neutral; the fill may carry a whisper of spectrum").
