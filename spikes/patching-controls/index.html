Patching selection & controls — R3 spike

Patching maps object space (lamps with 2D position) onto output-port space (linear lamps). This playground explores the two light languages (chase = blue start / red end / sweeping dot, for "is this mapped correctly"; breath = white fade + dimmed field, for "which lamps are these"), the unwrapped lamp strip that represents both spaces on screen, and where the patching controls live — the toolbar stays Mapping-parity; the adjust surface grows elsewhere. Everything animates; drive it from the strip below.
