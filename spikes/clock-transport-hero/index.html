2 · Piano reel — FUTURE · ★ KEEPER (round 2: "almost exactly what I imagine the input recorder being") · not clock scope

When the proper input subsystem lands, every input is recorded — continuously, by design, like a flight recorder — onto lanes riding the same timebase: taps as hits, faders as curves, knobs as steps, keys as piano-roll bars. Same transport, same scrub, same zoom: drag the reel back and the tape, phasors, and digits all rewind with it; lane labels read the value under the playhead. Ahead of the live edge there is nothing yet — the darker region is unrecorded future. This card is here to test that the tape idiom scales, so choosing it for the clock now doesn't paint us into a corner.
