Card overlay — full-art gallery cards

Today a project/explore card letterboxes its preview into a fixed 8:3 strip and stacks title + metadata + action chips below it — with the aspect-fit fix (G1-B: fit, never stretch), a square-ish lamp field occupies a small centered patch of that strip. This spike explores the deferred G1 direction: the card shows the full square-ish preview and the text rides a semi-transparent overlay. The hard question isn't the happy path (name + one line) — it's where a package card's meta density goes: up to four status lines, a blocked headline + remedy, and one or more action chips. Concepts differ mainly in that answer. Remember: on the real card, hover also buys live rendering — hover chrome must not bury the motion it just paid for.
