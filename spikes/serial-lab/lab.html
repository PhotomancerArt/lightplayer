Comms lab over Web Serial

lp-link and the lab's host half (spikes/link-lab-wasm, the same code as lp-cli link lab) against a test_comms_lab board, through Chromium's Web Serial. Needs a granted port (the bench-block policy, just serial-grant) and exactly one Espressif port attached. Query: echo, stream (seconds), min, max, inflight, seed, logs, loglen, stall (a board stall, ms), bufferSize (Chrome's default 255), stallEvery / stallMs (a busy main thread), name. Plan reliable-device-link, M3.
