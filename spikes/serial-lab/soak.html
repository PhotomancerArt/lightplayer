Link soak: Web Serial raw reader

Reads a soak_link board's bytes through Web Serial, as Studio's read pump does, and posts the raw capture to the lab server for lp-cli link soak-verify. Needs a granted port (the bench-block policy, just serial-grant). Query parameters: bufferSize (Chrome's default is 255), seconds, min, max, rate, logs, encoding (packed|json), stallEvery/stallMs (a busy main thread: a synchronous spin of stallMs every stallEvery ms, as a long wasm task would be), name (the capture's file name stem).
