Palettes — chooser · cycle configs · editor · inheritance

SHIPPED — this design landed as the M4 palette chooser (PR #348: swatch control, anchored popover chooser, editor takeover; §6B mode-tabs as gated). The spike stays as the design record; the shipped truth lives in lpa-studio-web's palette stories.

Companion to the palette exploration spike (planning: 2026-08-03-1803-palette-exploration-spike). Thesis, revised by D17 + the landed TimeProduct M2 (PR #328): the chooser writes a GradientConfig = static(Gradient) | cycle{set, step, fade} — a plain held value, P3-pure — and the shader's fill path resolves it, making a phasor query for cycle configs exactly the way kind:"phasor" slots already do. No cycler node, no stateful control; the clock owns all integration. Round 3 reworks §6 around that (the round-2 cycler-node card is dead) and speaks the landed vocabulary: the phasor Speed knob with unit-aware readouts (2/s · 3/min · 15/hr), the clock-face phasor registry (green = private, violet = SHARED, φ + cycle count), and panel:"show" for default-bound publicity (PR #317). Engaged/captured treatment is candidate gold — deliberately not the bound-violet family (P6, P-Q2).

6 · Choosing a cycle — GradientConfig (D17, post-TimeProduct)

Round 3 rework. The round-2 cycler-node card is dead — D17 killed it the same way the phasor node died. What ships instead: the chooser writes a GradientConfig = static(Gradient) | cycle{set, step, fade}, and the shader's fill path resolves it — a cycle config makes a phasor query (one full-cycle phasor, period = set×step, so index + blend are pure in φ and scrubbing replays exactly). The rate control below is the landed phasor Speed knob idiom verbatim: label "Speed", unit-aware readout, right = faster. Every live card also renders the clock-face registry row its phasor would produce (green = private, violet = shared). B/C/D are three rival chooser shapes for building a cycle; E is the sharing-semantics demo. Grab any cycling swatch (P5): the writer takes a static snapshot — reins in hand — and ↺ releases back into the cycle. Lean: C — no mode switch; a cycle is what you get by adding a second palette, and the tray IS the config. Language question for the gate: the chooser says step ("every 4 s") but the landed knob says Speed ("15/min") — both shown live; the knob's language is marked PROVISIONAL in the code, so this spike gets to decide.

7 · Dynamic palettes (D14) — generators are content

A dynamic palette is a normal compute shader producing a Gradient value — the same produced-slot contract FluidEmitter sets use today; no special engine feature. Below, a mock "aurora-breather" mutates its stops every tick; the panel control follows in Read (◈), the stops inspector shows it's just a value changing, and grabbing the swatch freezes the moment you captured (P5) — the generator keeps running underneath, shadowed in this scope (P4). WLED's * Random Cycle, * Color 1, audio-morph — all this one pattern. The only later nicety: a blessed gallery module so it's discoverable without GLSL. Unchanged by D17: plain time-driven cycling moved into the config (§6), but a generator that derives stops from other channels is still a normal compute producer.

8 · Who ships a shared cycle? (open — needs Yona)

D17's one open remainder. Panel state is performance-only — it stays on the device and never ships with the project. So when "these four palettes, every 4 s" is part of the art, who is the authored writer of bus:palette? Two candidates, not live — this is an information-architecture question, not an interaction one. Lean: A — keep the Palette node, shrunk to a config source with a set-editor face and zero time logic (it writes the config; the consumers' fill paths query the phasor). It preserves the "standard set of built-in nodes" direction and gives the shared cycle a face, probe row, and add-menu discoverability. B is the honest v1 cut if the node feels premature.

9 · The panel dropdown — B's tabs, anchored on the panel (round 3c, live)

B chosen at the 3b gate, so the popup now carries B's structure — Palette | ↻ Cycle tabs — and the whole thing is anchored under the panel row, dropdown-style, overlaying the controls below it (gold join = the engaged writer). The tabs map 1:1 onto GradientConfig = static | cycle, and they dissolve round 3b's ambiguous list-click rule: in the Palette tab a click selects, in the Cycle tab a click adds. The closed row is mode-adaptive — static shows a plain strip + name (any palette control), cycle shows member chips + rate — which retires the a-vs-b variant question. ✎ (cycle chips, project rows) still flips the popup into the editor. The anchoring here is a spike-grade approximation: popup joined to the row with a shared gold outline. The REAL join is the contiguous merged-outline system (spikes/contiguous-popup) which lives with the story world — composition, dismissal, layering, and phone presentation are story questions for M4, not spike questions.
