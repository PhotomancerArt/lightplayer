Design-language refresh — spike playground

Thesis: LightPlayer is an LED art engine and should feel like one — today the chrome is a flat pale-green wash with weak structural contrast, flat popovers, and near-invisible hovers. Each stage below applies a complete candidate direction to the same composite mini-app (chrome bar, example cards, detail popover, buttons, status chips, tree, focus ring). Status hues (violet=binding, amber=unsaved, orange=health, gold=engaged, blue=live) are held constant in every direction — the refresh moves surfaces, accent, materials, and interaction light, not meaning.

Explore: Hover anything for real, too — every direction styles its own hover light.

Faithful reproduction of today's tokens, verbatim from style.css. Pain points annotated at right.

  • 1Structural contrast ~1.3:1 — border #2a3138 on surface #171b20 is nearly invisible; panels, cards and tree read as one flat sheet.

6Candidate standards (Aurora)

The re-theme is a ~50-line edit to style.css :root — token discipline is already near-total (~2105 token usages, 7 stragglers). These are the rules the winning direction would be written down as.

New token groups

--glass-bg / -blur / -sat / -edge overlay material
--color-focus-ring NEW — a11y gap
--spectrum brand, moments only
--glow hover bloom color

Rules

  1. Status hues never move. Violet=binding, amber=unsaved, orange=health, gold=engaged, blue=live, stripes=error/debug. Chrome may not borrow them.
  2. Glass is for overlays only — popovers, sheets, card footers. Resting surfaces stay opaque (readability + paint cost).
  3. Multi-color is a moment, not a wall — the iridescent ring is the hover/press/drag language (ruled 2026-08-29); brand mark and hero keep the spectrum; never resting chrome, never selection (stays neutral).
  4. Structural contrast floor: borders ≥ ~1.8:1 against their surface; raised surfaces ≥ 1 visible step.

Consolidation debt (with the refresh)

  1. ~70 ad-hoc button class strings (site chrome, share, settings, account) fold into ActionButton / InlineButton.
  2. 7 raw red-* classes in devices_page / local_store_banner move to error tokens.
  3. Focus ring token applied everywhere keyboard reaches.
  4. Full baseline flip: ~1938 story PNGs re-baseline in one PR (merge-is-acceptance).
