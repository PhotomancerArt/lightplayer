2. The shader card — where does the space declaration live?

Three homes for the same ShaderSpace slot (primary variant + per-target cells) on a faithful shader-card face: A a control in the settings strip that expands in place · B a dedicated space section, always visible · C a header identity badge, with the editor behind the advanced drawer. The mismatch toggle (top strip) shows the D1 cross-validation: declared 1D but the GLSL defines render(vec2). All three edit the same state — flip the primary in one and the others follow.

A — settings-strip control, expands in place

Space sits with the other knobs; the cells stay one click away. Cheap for the 90% of shaders that never touch their cells, but the declaration competes with performance controls for the strip.

B — its own space section ✓ lean

The declaration is identity, and identity gets a rail label — same rank as output/settings. Cells read as the unified enum they are. Cost: permanent vertical space on every shader card.

C — header badge + advanced drawer

Ambient identity (the 1D badge rides beside the kind label — click it to open the editor), zero face cost. Risk: the projection cells are buried where nobody learns they exist. A hybrid — C's badge opening B's section as a popover — is one gate answer away.
