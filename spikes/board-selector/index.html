Board selector — setup panel spike

The provisioning form's board choice, workshopped as a component. Thesis: we usually KNOW the chip (boot banner), so the selector should feel like confirming a good default, not filling in a form — quiet chrome (no grey fills, no tag noise), chip-not-board language, an image for every choice including Generic, and a calmer panel rhythm. Click boards in any concept; the exploration strip drives chip evidence, the served-board set, and the default-name formula everywhere at once.

1 · Current production (baseline)

Faithful repro of what PR #277 ships: bordered rows, grey selected fill, "matches detected chip" tags, "BOARD detected:" label, dashed text-only generic, the walk-away line. Kept comparable so "leave it" is a real option.

2 · Tiles

Image-forward tile grid — the board IS the picture. Selection is an outline + check, no fill. Generic gets its own silhouette tile. Reads like choosing hardware, scales to a future multi-board world as a grid.

3 · Quiet list

No boxes at all: hairline-separated rows with a radio dot. The calmest treatment; selection reads from the dot + text weight. Closest to the current structure with every piece of chrome removed.

4 · Collapsed select

The choice presents as ONE row showing the current pick (best match pre-selected when the chip is known); tapping expands an inline menu. Most compact — the happy path never opens it. The panel reads name-first.

5 · Detected-first hero

Leans hardest into "we already know": the matched board renders as a small hero (bigger art, chip line under it) with a quiet "use a different board" escape. When the chip is unknown it degrades to the quiet list.
