Device reset / flash / provision lifecycle — design spike

Post-M8′ walk feedback (Yona, iterated). Setup is in the card: a new device's tab IS the setup form — a date-based default name + one Flash button, no popup, no confirm, no separate naming. Heavy ops (flash / erase / reset) then elevate the card — the same card lifts and grows into a focal, walk-away-safe progress panel with a collapsible terminal. Destructive ops (erase) keep a confirm; a blank board doesn't. Explores: (A) set up a new device, (B) factory-reset from the editor + recover, (C) firmware update. Cards are ~320px. Click the buttons (or the stage) to step; everything is inert.
