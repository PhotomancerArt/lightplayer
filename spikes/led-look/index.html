How Studio draws LEDs

Yona liked the pattern review page's lamps — a round glow of colour for each LED, on black — and asked to try it in the app. Today Studio fills each lamp's voronoi cell flat (column A). This page puts that next to the review page's glow dots (B), the cell as a dim fill with the glowing dot inside it (C — our reading of "a circle of colour inside the shape"), and two more ideas: the glow clipped to the cell so light fills the shape but stops at the seam (D), and a cheap glow made by blurring small dots in one pass (E), which is the version that could survive a 30,000-lamp dome. Every tile uses the same lamp positions, the same pattern maths (the real radial-gradient and twinkle shaders from the pattern set, ported line for line), and the same linear-light → screen conversion Studio already does. The dot size comes from the lamp spacing each view measures itself (median nearest-neighbour distance — the number Studio's cells are already sized by).

2Up close — the PLAYFUL choker

The same 73 lamps at panel width, where the difference between the concepts is easiest to see: whether the letters read, whether neighbouring lamps blur into a line, and whether the shape survives when most lamps are dark (try Twinkle).

3In place — gallery cards

The card thumb is 256×192 with the lamps inset 6%, exactly as thumb_poster.rs draws it. At this size a dome lamp is one or two screen pixels apart, which is where glow either becomes texture or becomes mush.

4Cost at dome scale

Each way of drawing, timed in milliseconds per frame on this machine (M2 Max, Chrome), on an 840×840 canvas — a lamp view at 2× pixel density. Median of 20 frames, including the time for the GPU to finish. Green is under 8 ms (half a 60 fps frame, leaving room for the rest of Studio), amber under 25 ms, red is too slow to animate.

Pre-filled: 2026-09-25 on Yona's M2 Max in Chrome 152, with the machine under very heavy load (load average 80–170) — ballpark only; C and D at 30k were taken in an earlier pass.
