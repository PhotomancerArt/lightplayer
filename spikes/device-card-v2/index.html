Device card v2 — the four zones, dressed · round 2

Gate-1 rulings applied. A · Stage is the card, and it grows a project section inside the state zone that owns the project verbs (Open · Put it on the board · Remove project) and the empty face; the footer keeps the device verbs (Disconnect · Reset · Factory reset · Forget) as reserve-width chips and no menu. Terminal Preview

1 The converged card, across its states

One renderer, every state at once, at a three-up gallery width. Header: title · status · board · chip · MAC · fw. State zone, one box with separators: state line · bar slot · preview · meta · verb row, every row a fixed height, so a board event (a heartbeat, a fault, a lost link) can never move the card — the readout under each card measures it. The verb row carries Open + Remove project, or the gallery trigger + Put it on the board, or the board pick + Flash. Terminal: T1. Footer: the four device verbs. Arming any destructive chip marks the whole card.

2 The footer, measured

Reserve chips versus the shipped prefix column at the same width, live-measured. Drag the width: the shipped row shifts its neighbours as soon as it is full; Reserve never does. Project verbs are gone from the footer, so the row is four verbs wide at most.

3 The terminal — T1 with line processing

Natural order, pinned to the newest line, typed colours, decoded wire frames. Three processing rules, each exercised by a control above: cap — the fold keeps the last 200 lines and the panel says how many it dropped; repeats — an identical consecutive line collapses into one row with a ×N badge (the fold already collapses immediate repeats; this shows the count); long lines — anything past 160 chars folds at 120 with a click-to-expand tail, so a JSON blob never scrolls the panel sideways or eats ten rows.

4 The picker — gallery popover

The empty face's trigger opens a tabbed grid of the gallery's own cards (Examples · My projects · New) with their poster thumbs; the board pick uses the same trigger, filtered to the detected chip with the filter stated and escapable. Toggle the 40-project library above: the face stays one row.

5 The roster — disconnect → disappear; pending link; add card

The roster shows what is plugged in. Unplug a board and its card leaves; plug it back and it returns, remembered name and all. Boards Studio remembers but cannot see sit behind one quiet line at the bottom of the grid, not as cards — the line is the only place Forget lives for a board that is not here. Below it, the pending-link card (identifying, then needs firmware) and the add card in the same idiom.
