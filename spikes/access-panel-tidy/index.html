Round 1 gate (Yona, 2026-10-02): list = 1B, grouped by name. Passwords: “make it simple — one box for play password, one for edit. Button to regenerate. All the add, and choose and crap is too complex. Two rows, with a checkbox/toggle, default to a random pw, let the user override.”

What happened on the choker (lp-cli link capture … --request accessList, XIAO C6 10:bd:a3:b0:8e:30): 16 entries, all “Brave on Mac”, added Sep 26 → Oct 2. Each worktree’s dev server is its own origin, so its own browser key; every USB plug-in from a new one adds a copy. 16 is the board’s cap, and the next add is refused silently today.

Round 2 — one panel. Keys fold by name with a count and a “Keep this one”; the header counts toward 16 and a full board says so, with Make room. Below the list, Passwords is three switches and nothing else: Anyone nearby, Play password, Edit password. Each password row holds a random one already; turn it on and that’s the password. Click the box and type to replace it (the whole thing is selected), ↻ for another, and a changed password saves with Save or Enter. No names, no tier picker, no second screen.
