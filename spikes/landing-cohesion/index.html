Landing cohesion — one designed front page

Thesis: the landing reads as stacked sections, not one designed page — headings are light, and there are no doors to Docs or Supported boards. Four structures below, all in the post-Aurora language (neutral chrome, spectrum = moments, iridescent-ring hover). The hero keeps demonstrating (live shader triangle); Explore stays hidden — "try the simulator" means opening an example. Every concept ends in a real page footer.
