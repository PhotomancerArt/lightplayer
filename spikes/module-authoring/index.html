For "export": R7 may unify, not collide — a module exports channels, a project exports modules (same idea: a container's curated outward interface); the real collision is Share's "Export zip" (→ "Download zip"). design language (draft — workshop)
Naming the layers so the surfaces can talk about them consistently.
projectstandalone an authoring container. No exports — nothing to import; you can still open or fork it. Today's five examples are this.
workbench projecthas exports a project whose manifest designates ≥1 module folder as importable. The unit T1 ships. "Workbench" is the role of everything outside the exported folders.
modpackT3's object a curated, licensed collection of workbench projects + browse metadata (spaces, authors, licenses). Explore browses packs; packs reference projects; projects export modules.
