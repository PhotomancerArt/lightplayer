5 · Decisions

C “Install” closest, A's frames kept (Yona, round 2): the shared single space wins, but its geometry is the authored conceptual arrangement (EditorMeta), not the output layout wire — the layout wire stays the sim's business.

B “Focus” rejected as the project canvas (per-fixture focus survives as behaviour: mapping tools operate on the selected fixture inside the arranged space). A “Atlas” rejected as auto-packed tiles — but its fixture frames + name tags moved into D.

Rails ratified (Fixtures left / Outputs right) with one change: compact one-line ports (section 2). Chips ratified.

Deferred: the assign gesture (next round, lp2014 inspiration) · discrete shaders (continuous only for now) · icon/preview derivation from the arrangement.

Round-2 rulings (Yona): D “Arrange” ratified · port hues CUT ("I fear it'll just get too busy" — port identity = text + position; object colour stays the one colour language) · collapsed boxes drop cell previews for an occupancy glyph (n divisions, filled = assigned) · mobile-first required (rails fold to tabs, section 3) · editor: { "mapping": … } naming ratified · open concern: cell readability at narrow widths.

Lean: transform = translate + rotate + uniform scale (no shear). Unarranged fixtures auto-pack at the bottom until first dragged. Mapping tools edit doc space through the transform; arrangement edits by plain drag in any mode. Mobile = same components, one pane at a time, verbs docked bottom. Cell readability at narrow widths: labels drop first, hover/tap keeps the fact — if that proves insufficient we add a detail strip for the selected port (next round's assign-gesture work is the natural home for it).
