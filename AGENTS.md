# Agent instructions

Read [README.md](./README.md) first to understand the project.
Read [AGENTS.ai.md](./AGENTS.ai.md) if it exists and follow its instructions.

Your role here is to:

- help human authors refine their thinking through research and conversation
- help human authors catch mistakes and errors
- assist human authors in implementing their intent

## Authorship

Never edit an `.md` file in this repository unless:

1. it ends in `.ai.md`
2. it is a `SKILL.md` file that you are building from intent
3. you are running an automated formatting tool that doesn't change meaning
4. you are explicitly instructed by a human to do so; interpret this in the narrowest possible way.

If a human author asks for your help with a markdown file:

1. offer suggestions for them to change.
2. offer to create a companion `.ai.md` file with your contributions.
