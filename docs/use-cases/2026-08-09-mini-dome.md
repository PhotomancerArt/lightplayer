# The mini-dome — N-way symmetric repeat, re-patched every install

The dome archetype: a structure built from **identical repeated
units** (panels, sectors, struts) whose **mapping never changes**
but whose **plugging changes every single build**. The physical
crew connects units to whatever jack is nearest and the software
is expected to sort it out afterwards.

The concrete cases:

- The zook dome: ~1500 LEDs, one strut path repeated with 5-way
  symmetry, five controller ports of 300 LEDs each. The as-built
  plugging is a permutation — sector *k* landed on port
  `(1,5,4,3,2)[k]` — which today lives hand-coded in the example's
  channel order: a patch file trying to be born.
- The radiance dome (lp2014 era): ~190 panels of 119 LEDs across
  ten controllers, plus always-lit door fixtures sharing outputs.
  Roughly **90% of all clicks** in the old software were dome
  patching, because "plug into random jacks, fix it in software"
  beats careful cabling on a build site.

## Demands on the system

- **Instance-grain patching.** The patchable unit is the repeat
  instance (a panel, a sector) — a UI grain over object-relative
  storage; storage stays `(object, channel range)`.
- **Stable object identity** in the mapping doc, so patch entries
  survive edits to *other* objects (map2d format 3).
- **Per-entry direction and rotation.** A panel plugged backwards
  needs `reversed`; a symmetric panel seated in the wrong
  orientation needs an offset stepped by a meaningful stride (the
  panel's edge length) — "rotation is fake but very useful."
- **Multi-port, multi-output scatter.** Instances land on arbitrary
  ports of arbitrary outputs; the patch view must show every port
  as a row and every instance's destination.
- **Bulk operations.** Swap two ports, shift a port's contents,
  clear the patch for a *selection* of fixtures (the dome
  re-patches every install; the orb next to it is wired forever).
- **Live hardware feedback.** Select an instance, see it pulse on
  the physical build (the lp2014 `debugChannels` workflow —
  patching is done standing next to the dome).
